# 小米手机「干净化」实测手册（给小白 + 给 AI 用）

把小米 / 红米手机（澎湃 OS / HyperOS）里**自动收集你的信息、往外发数据的预装组件**，安全地清理掉——不用 root、不用刷机，只用一台电脑和一条数据线。

这不是一份网上抄来的「精简列表」。这里面的每一条，都是在一台真手机上一个一个卸下来、验过功能、踩过坑之后记下来的账。

- 实测机型：Redmi Note 15 Pro+，澎湃 OS 3（安卓 16），2026 年 11 月实测
- 战绩：主空间卸掉 47 个组件、分身空间 1 个、禁用中和 2 个，手机日常功能全部正常

## 怎么用这份东西

**最省事的用法（推荐）**：把 [`SKILL.md`](SKILL.md) 整个发给你的 AI 助手（Claude、ChatGPT、豆包、任何能读长文的 AI 都行），然后跟它说一句：

> 「照这个手册，带我把手机清理一遍。」

它会一步一步带你做：先盘点你的手机里有什么，再分批清理，每批做完都检查手机还正不正常。

**自己动手**：照 [`packages.md`](packages.md) 的名单对照着来，但务必先看完下面的风险说明和 `SKILL.md` 里的「风险登记表」。

## 先说清三件事（重要）

1. **这里的「卸载」不是真删**。用的方法只对「你这个用户」隐藏组件，系统出厂文件还在。一条命令就能装回来（手册里有）。所以整个过程可逆，这是它敢动手的前提。
2. **名单不能闭眼照抄**。不同机型、不同系统版本，装的东西会有出入。手册的流程是「先给你自己的手机拍一张全量清单，再对照名单分级」，不是拿着名单无脑卸。
3. **快不得**。一次只清一批（五到十个），清完立刻验活：打电话、收短信、微信发图、定位、装一个应用。这些都正常了，再清下一批。图快一把梭，出问题都不知道是哪件的锅。

## 我们踩过的最大的三个坑（先有个心理准备）

- **手机管家是「承重墙」**。官方说它能卸，真卸了之后，系统选照片的功能会崩——因为小米把照片选择器悄悄绑在了管家身上。最后的办法是「留壳抽芯」：管家留着当空壳，把它收集数据的定时任务单独取消掉。细节在手册的风险登记表 R4、R5。
- **设置里点的「卸载」可能是假的**。有些系统应用在设置里点卸载，点完它还好好地在那儿（只卸掉了一个更新层）。卸没卸掉，不能看图标，要查系统记录。
- **关掉的开关会自己弹回来**。有个收集数据的开关，我们关了，它半小时后自己变回去了。别跟开关较劲——要盯的是「数据本身还在不在产生」，以及「到底是谁在写它」。手册里教了怎么把写手揪出来。
